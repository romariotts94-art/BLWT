# Black and White / BLWT

Полная копия проекта: публичная витрина, сервер, личный кабинет, админка, CRM, схема базы данных и исходные медиа.

- GitHub Pages: https://romariotts94-art.github.io/BLWT/
- Серверный сайт: https://black-and-white-cleaning.navy-ant-8163.chatgpt.site

## Два режима публикации

GitHub Pages обслуживает публичную главную, видео, каталог и предварительный калькулятор. Оформление заказа переходит на серверный сайт. GitHub Pages не запускает серверные API, базы данных, CRM или видеосигналинг.

Основной серверный сайт сохранён. Он пока работает в закрытом пилоте, доступ ограничен владельцем. Публикация этой витрины не меняет доступ к личным кабинетам, CRM и данным.

## Запуск

Node.js 22.13 или новее:

```sh
npm ci
npm run dev:pages   # публичная витрина
npm run build:pages # сборка в pages-dist
npm run dev        # полный серверный проект, локально
npm run build      # серверная сборка Vinext / Cloudflare
```

После загрузки файлов откройте Settings → Pages → Build and deployment → GitHub Actions. Затем запускается workflow `.github/workflows/pages.yml`; адрес будет `https://romariotts94-art.github.io/BLWT/`.

## Что сохранено

- `app/`, `components/`, `lib/`: интерфейс, серверные API, роли, заказы, сметы, CRM, сообщения, отзывы, видеосвязь.
- `db/`, `drizzle/`: схема и миграции базы.
- `public/`: фотографии, видео и иконки.
- `pages/`, `pages.vite.config.ts`: отдельная сборка GitHub Pages.
- `docs/`: архитектура и происхождение материалов.

Зависимости, кэш, локальная база и секреты не включены. `.openai/hosting.json` содержит идентификатор существующего Site, а не ключ доступа. Не переносите `.dev.vars` и `.env` в публичный репозиторий. Цены новых услуг предварительные; стоковые изображения не являются фотографиями выполненных заказов.
