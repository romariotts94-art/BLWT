# Подключение уведомлений поддержки в Telegram

Сайт сохраняет обращения в базе данных. Отдельный процесс `support:delivery` отправляет администраторам уведомление со ссылкой на обращение; отвечать клиенту нужно в кабинете сайта. Токен Telegram-бота и ID группового чата обязательны.

1. В Telegram откройте официальный аккаунт [@BotFather](https://t.me/BotFather), выполните `/newbot` и сохраните выданный токен в менеджере секретов сервера. Не вставляйте токен в исходный код, браузер или публичный чат.
2. Создайте закрытую группу поддержки, добавьте туда нового бота и разрешите ему отправлять сообщения.
3. Чтобы узнать ID группы, напишите в ней сообщение после добавления бота. На сервере выполните `curl "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/getUpdates"` и возьмите числовое `message.chat.id` из обновления. Команду выполнять только в доверенном терминале: не публикуйте URL и его вывод.
4. В защищённой конфигурации приложения задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_IDS`. Если групп несколько, укажите ID через запятую. Сохраните `DATABASE_URL` и `PUBLIC_ORIGIN` из конфигурации приложения.
5. Запустите `npm run support:delivery` как постоянную службу на том же сервере, где доступна PostgreSQL. Для systemd настройте автозапуск и перезапуск после сбоя; не запускайте несколько копий без необходимости.
6. В кабинете администратора откройте «Поддержка»: статус Telegram должен показывать, что он подключён. Новые обращения будут сохраняться на сайте и попадать в очередь уведомлений. Если Telegram временно недоступен, процесс повторит попытку.

Локальная проверка в этом checkout показала, что `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_IDS` не заданы. Без токена и ID группы подключение к реальному Telegram не завершить.
