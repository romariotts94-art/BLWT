# Как вывести Black to White в поиск

Проверка 5 ноября 2026 года. Основной адрес: `https://blackandwhite-mos.ru/`. Рабочий порядок проекта: локальная проверка → визуальная приёмка → GitHub `main` → сервер → проверка опубликованного сайта.

## Что видно сейчас

| Проверка опубликованного сайта | Результат |
| --- | --- |
| Главная и `/care-guide` | HTTP 200, у каждой есть заголовок H1 и серверный HTML |
| `robots.txt` и `sitemap.xml` | HTTP 404 |
| `www.blackandwhite-mos.ru` | HTTP 200 с копией главной без перенаправления на основной адрес |
| Canonical главной и `/care-guide` | Не указан |
| Отдельные адреса услуг | Пока нет: услуги показаны в разделах главной страницы, ссылки вида `/#services` не образуют отдельных страниц |
| Состояние индексации | Не установлено: для точного ответа нужны Яндекс Вебмастер и Google Search Console |

Отсутствие `robots.txt` или sitemap само по себе **не запрещает** индексирование. Карта помогает обнаружить страницы, а единый адрес и canonical помогают объединить варианты URL. Публикация файлов и отправка карты **не гарантируют** попадания в выдачу и позиции.

## Что подготовлено локально

1. Добавлены `public/robots.txt` и `public/sitemap.xml` с двумя реальными публичными страницами: главной и `/care-guide`. API закрыт от обхода через robots; закрытые кабинеты не перечислены в карте.
2. В `Caddyfile` настроено постоянное перенаправление `www` на `https://blackandwhite-mos.ru` с сохранением пути.
3. Для главной и Академии заданы отдельные title, description и canonical. Формулировки отражают роль платформы: подбор независимого исполнителя, без обещания, что сам оператор выполняет уборку.
4. Для `/live` задан `noindex`: страницу заказа с приватным эфиром нельзя предлагать поиску.
5. В подвале главной добавлена обычная HTML-ссылка на Академию, чтобы робот и посетитель могли перейти на вторую публичную страницу.

Локально обе страницы, robots и sitemap отвечают HTTP 200; в XML два URL. Настройку Caddy и опубликованные метатеги нужно проверить **после** выкладки. Эти изменения пока не отправлены в GitHub и не установлены на сервер.

## Порядок запуска индексации

### Шаг 1. Выпустить локальные изменения

Посмотреть локальный сайт, затем отправить проверенную версию в `main` и развернуть на сервере. После публикации проверить HTTP 200 для `/robots.txt` и `/sitemap.xml`, HTTP 301/308 для `https://www.blackandwhite-mos.ru/` на основной домен, title/canonical на обеих страницах и отсутствие `noindex` на них. Проверить, что `/live` имеет `noindex`, а публичные страницы доступны без входа. Временные сбои хостинга отслеживать: если робот получает ошибки сервера, обход и обновление выдачи замедляются.

### Шаг 2. Подключить инструменты поисковиков

Добавить `https://blackandwhite-mos.ru/` в [Яндекс Вебмастер](https://www.yandex.ru/support/webmaster/ru/service/quick-start) и домен в [Google Search Console](https://support.google.com/webmasters/answer/9008080?hl=ru). Подтвердить владение DNS-записью или выданным сервисом HTML-файлом. Токены подтверждения берутся **в личном кабинете сервиса**: случайные значения или общие файлы из примеров не подойдут. Проверить отчёты об обходе, исключённых страницах и ошибках.

### Шаг 3. Передать карту и регион

Указать `https://blackandwhite-mos.ru/sitemap.xml` в [Яндекс Вебмастере](https://yandex.ru/support/webmaster/ru/indexing-options/sitemap) и [Google Search Console](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap). Уточнить в [Яндекс Вебмастере регион](https://yandex.ru/support/webmaster/ru/site-geography/site-region.html): услуга предлагается в Москве. Это не основание придумывать московский офис или менять зарегистрированный адрес ИП. Запросить проверку главной и Академии через инструменты проверки URL. Появление в выдаче может занять время.

### Шаг 4. Сделать страницы для реального поискового спроса

Сейчас у поисковика только две отдельные публичные страницы. Подготовить отдельные адреса для основных направлений, например `/cleaning/regular`, `/cleaning/general`, `/cleaning/after-renovation`, `/cleaning/office`, **если** эти услуги фактически доступны в Москве. На каждой странице нужен свой понятный заголовок, конкретный состав работ, предварительная стоимость и её условия, ограничения, порядок выбора исполнителя и переход к оформлению. Тексты должны честно показывать роль Black to White как площадки и ответственность независимого исполнителя. Не создавать десятки почти одинаковых страниц под районы или запросы и не копировать тексты конкурентов. После публикации добавить настоящие адреса в sitemap и связать их HTML-ссылками.

### Шаг 5. Измерять результат

Еженедельно смотреть в кабинетах поисковиков: какие страницы обнаружены и индексируются, ошибки 4xx/5xx, поисковые запросы, показы и переходы. Если подключать аналитику, сначала сверить её с опубликованной политикой обработки данных, согласием на cookies и фактическими настройками сбора. Позиции и сроки не обещать: они зависят также от спроса, качества материалов, конкуренции и доступности сайта.
