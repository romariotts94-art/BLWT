### Решения владельца

- Оператор платформы — ИП Титов Роман Викторович. Платформа помогает клиенту найти независимого исполнителя; договор уборки заключается с конкретным исполнителем. Нельзя объявлять платформу полностью освобождённой от всех законных обязанностей.
- На запуске — только Москва. Допускаются исполнители НПД и ИП; частые подработки обычных физлиц в модель запуска не входят. Проверка актуального статуса НПД по ИНН остаётся.
- Первый подходящий исполнитель может принять предложение автоматически; клиенту нужны сведения о нём и возможность отказаться или запросить другого. До начала работ обе стороны подтверждают договор с конкретным исполнителем.
- Целевая экономика — 35% платформе, 65% исполнителю. Т-Банк отказал в «Мультирасчётах» из-за недостаточного оборота. Подходящий провайдер распределённого платежа ещё не выбран и не подключён. До подписания договора, проверки чеков, возвратов и API настоящую оплату не включать.
- Порядок поставки: локальная копия → проверка сценариев и визуальный просмотр → `main` на GitHub → рабочий сервер → проверка сайта в интернете.
