# Актуальная версия на другом компьютере

Репозиторий: https://github.com/romariotts94-art/BLWT — ветка main.
В нём находятся исходники приложения, изображения и видео из public/, схема и миграции базы, настройки сборки и package-lock.json.
На 7 ноября 2026 года код ветки совпадает с работающим релизом `651595a`; текущие ограничения запуска записаны в [срезе проекта](PROJECT-STATUS-2026-11-07.md). Более поздние коммиты с документацией не меняют образ на сервере.

## Скачать и открыть витрину

Установите Node.js 22.13 или новее и Git. В терминале:

```sh
git clone https://github.com/romariotts94-art/BLWT.git
cd BLWT
npm ci
npm run dev:pages
```

Откройте http://127.0.0.1:5174/BLWT/ — публичную витрину с локальными фотографиями, анимациями и калькулятором. Кнопки оформления заказа в этом режиме ведут на адрес серверного сайта, заданный в github-pages/main.tsx.

## Полное приложение и сервер

```sh
npm run dev
```

Адрес: http://127.0.0.1:5173/. Для работы личных кабинетов, заказов и других серверных функций нужны настроенные подключения и база данных. Без них интерфейс может показывать ошибку загрузки данных — наличие исходников само по себе базу не восстанавливает.

Для своего VPS используйте .env.example и docs/RUSSIA-DEPLOYMENT.md. Настоящие пароли, .env, данные заказов и пользовательские загрузки необходимо переносить отдельно защищённым способом. Они не включены в публичный GitHub.

Копия исходного каталога действующего релиза также находится на рабочем столе в `BLWT-VPS-2026-11-03/black-and-white`. Она включает приватный серверный `.env` и закрытые снимки базы и загрузок от 7 и 8 ноября в `private-backups/`; последний — `production-2026-11-08/`. Там же лежат архивы служебных томов Caddy и TURN, контрольные суммы и `README.txt` с составом снимка. Папка `private-backups/` исключена из Git; не отправляйте локальный проект целиком в репозиторий и не публикуйте его архивом. Рабочие серверные тома продолжают жить на VPS; локальные файлы являются копией на момент снятия.

Для просмотра полного приложения 8 ноября собрана серверная Node.js-версия из этой папки и запущена на `http://127.0.0.1:5175/` с отдельной локальной PostgreSQL, восстановленной из свежего дампа. Почта, Telegram, Qwen, TURN и реальные платежи в локальном запуске отключены; это не зеркалирует внешние интеграции VPS. Старую отдельную витрину `npm run dev:pages` не используйте как представление действующего сайта: её код содержит прежние разделы и ссылки.

## Получать следующие обновления

Если в скачанной копии нет собственных незакоммиченных правок:

```sh
git pull --ff-only origin main
npm ci
npm run dev:pages
```

Локальные правки сначала сохраните отдельным коммитом или резервной копией. Не используйте сброс с удалением изменений для обновления.

GitHub здесь используется для хранения версий. Публикация при push отключена; при необходимости GitHub Pages запускается вручную во вкладке Actions.

node_modules и сборочный кэш не хранятся в репозитории: npm ci устанавливает зависимости по package-lock.json для вашей операционной системы.
