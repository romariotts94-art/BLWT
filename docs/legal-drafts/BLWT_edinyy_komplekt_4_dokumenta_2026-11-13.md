| Возвращено клиенту | Фактически возвращённая сумма |
| Итоговая оплаченная стоимость | Списано минус возвращено |
| Доля Принципала | 65% с договорным округлением |
| Комиссия Агента | Остаток после расчёта доли Принципала |
| Перечислено Принципалу | Подтверждённые банковские выплаты |
| Остаток к выплате | Доля Принципала минус перечисления |
| Переплата | Сумма излишнего перечисления, если имеется |
| Статус | Ожидает оплаты / оплачен / частичный возврат / возвращён / спор / закрыт |

## Раздел 2. Журнал денежных операций

Каждое подтверждённое банковское событие записывается отдельно.

| Поле | Содержание |
|---|---|
| ID операции | Уникальный номер записи |
| ID заказа | Связь с заказом |
| Дата и время | Время подтверждения операции |
| Тип | Списание / возврат / выплата / корректировка |
| Сумма | Фактическая сумма |
| Банковский идентификатор | ID операции провайдера |
| Статус | Подтверждена / отклонена / проверяется |
| Основание | Заказ, приёмка, решение о возврате или иной документ |

Авторизация карты без списания не включается в полученную выручку.

Повторное уведомление банка не создаёт вторую денежную операцию.

## Раздел 3. Контрольные сведения

По каждому заказу сохраняются:

- Подтверждение актуального статуса НПД исполнителя и дата проверки.
- Версия агентского договора и индивидуального договора уборки.
- Подтверждение приёмки результата клиентом.
- Сведения о кассовом чеке и фискальной операции.
- Сведения о передаче информации для учёта НПД в применимом порядке.
- Банковские идентификаторы поступлений, возвратов и выплат.
- Основания удержания спорной суммы, если она временно зарезервирована.
- Сведения об ошибках и исправлениях.

## Раздел 4. Правила расчёта

**Итоговая оплаченная стоимость** = подтверждённые списания − фактические возвраты.

**Доля исполнителя** = итоговая оплаченная стоимость × 65%, округление вниз до копейки.

**Вознаграждение Агента** = итоговая оплаченная стоимость − доля исполнителя.

**Остаток к выплате** = начисленная доля исполнителя − подтверждённые выплаты.

Если остаток отрицательный, сумма учитывается как переплата, требующая отдельного документального урегулирования.

Комиссии банков, эквайринга и выплат отражаются отдельно как расходы Агента и не вычитаются автоматически из 65% исполнителя.

## Раздел 5. Сверка

Реестр сверяется с банковскими операциями, кассовыми документами и данными заказов.

Отчёт агента формируется на основании реестра за соответствующий календарный месяц.

Ошибки исправляются новой записью корректировки. Первоначальные операции и история изменений сохраняются.

**Важно:** в реестр вносятся только фактические события. Тестовые платежи, демонстрационные суммы и внутренние начисления не смешиваются с реальными расчётами.
