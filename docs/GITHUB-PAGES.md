# GitHub Pages

Публичная главная собрана отдельно, из того же MarketingHome и общих тарифов. Видео и локальные изображения публикуются с базовым путём /BLWT/.

Кнопка оформления передаёт только тип уборки, площадь, дополнительные услуги, коэффициенты, дату и время на основной сайт через параметр quote. Серверный интерфейс валидирует значения, сбрасывает согласия и удаляет параметр из адресной строки. Имя, телефон, адрес и сообщения в ссылку не включаются.

Публичная витрина использует тарифы из lib/domain.ts. После изменения тарифов в админке синхронизируйте их с исходным кодом и публикацией Pages. Окончательная смета определяется сервером; витрина явно показывает предварительную стоимость.

Отзывы остаются на основном сервере; публичная витрина не запрашивает закрытые данные и не содержит вымышленных отзывов.
